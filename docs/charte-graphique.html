06 — Règles d'usage

Règle 1

Séparation des espaces

Ne pas mélanger les couleurs employer.* et extra.* dans un même espace. Le gradient de marque est réservé à l'espace public et aux éléments transversaux.

Règle 2

CTA primaire

Espace Pro → bouton employer.primary. Espace Extra → bouton extra.primary. Un seul CTA primaire par vue.

Règle 3

Accessibilité

Ratio de contraste minimum 4.5:1 pour le texte de corps. Ne pas utiliser #F7B742 sur fond blanc sans texte sombre (#503C1B). L'ambre seul est un fond, pas un texte sur blanc.

Règle 4

Gradient — usage restreint

Le gradient #22345E → #FDBA3B → #F15A29 est réservé aux zones hero, aux dividers, et aux éléments de marque. Pas sur les boutons internes.

Règle 5

Icones Lucide

Utiliser exclusivement la lib lucide-react (déjà en dépendance). Taille par défaut : 16px inline, 20px dans les boutons, 24px standalone.

Règle 6

Mode sombre

Le dark mode via darkMode: ["class"] est configuré. L'espace public supporte les deux modes. Les espaces Pro et Extra sont actuellement en mode clair uniquement.
